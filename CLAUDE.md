# Club website

The Claude Builder Club @ Cambridge events page. Plain HTML, CSS and JavaScript, no build step.

## Files
- index.html: the page
- events.js: the list of events (the only place event data lives)
- app.js: draws the events on the page
- style.css: all styling

## Commands
- Run the tests: node --test
- Preview: open index.html in a browser
